# Spritorienteering Generator

A lightweight React + Vite starter for the Spritorienteering Generator web app.

## Getting started

Requires Node.js 20.19+ or 22.12+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build

## Project structure

- `src/App.jsx` — the app's starting screen
- `src/App.css` — component styling
- `src/index.css` — global styling
- `src/main.jsx` — React entry point

This first version is intentionally just the React shell. Generator behavior will be added next.
